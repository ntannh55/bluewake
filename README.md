## 🎮 What Is bluewake?

bluewake is a fan-made project that lets you play **The Legend of Zelda: The Wind Waker** on your computer or phone without needing an emulator or special technical skills. It's a "recompiled" version, which means the original game code has been translated to run directly on modern operating systems. The result? Smoother performance, better graphics compatibility, and a much simpler setup than traditional emulation methods.

Think of it this way: instead of using a translator (an emulator) to speak to your hardware, bluewake speaks the native language of your Mac, Windows PC, Linux machine, or iPhone/iPad directly. Everything runs faster and more reliably.

## 🛠️ Troubleshooting

**"I see a black screen when I launch the game."**
- Ensure your graphics drivers are up to date. Visit your GPU manufacturer's website (NVIDIA, AMD, Intel) and download the latest drivers.

**"The game runs slowly."**
- Close other programs running in the background. Lower the resolution in the game's settings menu. Check that your computer meets the minimum requirements above.

**"I can't find the game data file."**
- The game requires the original disc image (ISO) from your legally owned copy of Wind Waker. This is a 1.2 GB file. If you own the physical disc, you can create an ISO using tools like ImgBurn (for Windows) or Disk Utility (for macOS). The repository's FAQ section provides detailed help.

**"Windows blocked the file from running."**
- Some antivirus programs may flag unknown executables. Click "More info" on the Windows SmartScreen prompt, then "Run anyway". Add the extracted folder to your antivirus exclusions if issues persist.
